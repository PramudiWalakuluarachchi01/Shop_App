# 👟 Shoe Store App

A Flutter-based e-commerce mobile application that allows users to browse a collection of shoes, search products, filter by brand, view product details, and add items to a shopping cart.

The application demonstrates modern Flutter development practices such as reusable widgets, Provider state management, and responsive UI design.

---

# 📱 Features

* 🛍 Browse shoe products
* 🔍 Search products by name
* 🏷 Filter shoes by brand (Adidas, Nike, Puma)
* 📄 View detailed product information
* 📏 Select shoe sizes
* 🛒 Add products to cart
* ❌ Remove products from cart
* 📱 Clean and responsive UI

---

# 🛠 Tech Stack

* **Flutter** – Mobile app development framework
* **Dart** – Programming language
* **Provider** – State management for cart functionality
* **Material UI** – User interface components

# 🚀 Installation

Clone the repository

```
git clone https://github.com/PramudiWalakuluarachchi01/shop_app.git
```

Navigate to the project directory

```
cd shoe_store_app
```

Install dependencies

```
flutter pub get
```

Run the application

```
flutter run
```
